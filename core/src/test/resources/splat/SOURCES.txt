SplatFuzz の種と SplatRegressionCheck で使う、小さなガウシアンスプラッティングのファイル

すべて、Python (標準ライブラリと Pillow) で作ったもの (40 個の分布)。
  small.splat               .splat
  small_sh1.ply             標準の 3DGS の .ply (バイナリ、SH 1 次)
  mixed_be.ply              ビッグエンディアン、double と short の型、vertex の前に別の要素
  ascii.ply                 ASCII (改行は CRLF)、vertex の前に数が 0 の要素
  compressed.ply            PlayCanvas / SuperSplat の圧縮した .ply (chunk、packed_*、sh)
  v2.spz, v3.spz            gzip の .spz (版 2 は SH 1 次、版 3 は SH 2 次)
  v4_sh0.spz, v4_sh3.spz    Zstandard の .spz 版 4 (Raw と RLE のブロック、拡張のバイトあり)
  mode0/1/2.ksplat          .ksplat の圧縮の形式 0、1、2 (1 と 2 は SH 1 次、バケットの一部が端数)
  v2.sog                    .sog 版 2 (可逆 WebP、shN あり)
